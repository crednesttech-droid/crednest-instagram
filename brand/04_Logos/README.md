# CredNest logo assets

The existing CredNest icon is preserved. This kit adds wordmark compositions for social use; it does not introduce a redesigned icon or claim to contain a fully vector logo.

| Asset | Source and format | Use |
| --- | --- | --- |
| CredNest_Icon_Original_640.png | Original archived file, copied unchanged; 640 × 640 RGB PNG | Large reference and placements on a white tile. Its rounded-square corners contain opaque white pixels. |
| CredNest_Icon_Source_Transparent_120.png | Original embedded icon extracted from the company profile PDF; 120 × 120 RGBA PNG | Small logo placements on dark or light backgrounds. Corners have genuine transparency. Keep its displayed size at or below 120 × 120 px where possible. |
| Dark and light wordmark lockup SVG compositions | Existing transparent PNG icon embedded at 72 × 72 px, plus editable Manrope text | Consistent horizontal CredNest signatures. The composition is SVG; the icon inside remains raster. |

## Colour fidelity

The 640 px original contains lime **#B8FF5A** and ink **#07150F**, which anchor the kit palette. The PDF-embedded 120 px icon contains dominant lime **#BCFE61** and ink **#08150F**. That slight source colour shift is preserved rather than recolouring the logo. Antialiased edges contain additional colours.

## Editing and placement

- Install the bundled Manrope font files before editing the SVG wordmark text. Manrope is the new v1 typography choice; it is not claimed as the historical logo typeface.
- Use the light wordmark composition on dark backgrounds and the dark wordmark composition on light backgrounds.
- Scale compositions proportionally. Do not stretch, rotate, recolour or redraw the icon.
- Keep a clear area around the lockup equal to at least half the icon width. This is a new working rule for this kit.
- The original 640 px file is opaque. A white tile keeps its white corners visually consistent; it should not be described as a transparent asset.
- The 120 px icon is suitable for the supplied 72 px lockup placement. Enlarging it does not add detail.

A clean standalone vector icon was not found in the inspected CredNest source files. The PNG originals remain the identity reference. If a future original SVG, AI or EPS file becomes available, replace the embedded raster icon while preserving the mark's geometry.
