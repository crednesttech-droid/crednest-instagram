# Instagram templates

Six example layouts use the existing CredNest logo and verified profile positioning. These are layout masters for future posts; no content has been published.

- 01: Brand introduction, 1080 x 1350 px.
- 02, 03, 04: Three-slide credit-readiness carousel, each 1080 x 1350 px.
- 05: Working-capital service example, 1080 x 1350 px.
- 06: Story / Reel cover frame, 1080 x 1920 px.

Each PNG has a matching editable SVG. Install the Manrope fonts before editing the SVG in a vector editor such as Figma or Inkscape; font handling differs by editor. Text is retained as text, shapes as shapes, and the logo is an embedded original PNG. SVG import in Canva may flatten or substitute elements, so inspect the result there. Replace sample copy, then export at native dimensions.

House safe area: 88 px side margins. Story key content stays between y=250 and y=1660; preview the actual placement because overlays and crops vary. These are chosen design defaults, not claims about maximum platform dimensions.
